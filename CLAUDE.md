# CMA Study Dashboard

## Tech Stack
- React + Vite + TypeScript
- Tailwind CSS
- React Router DOM
- Supabase (auth + database)
- Zustand (state management)
- Recharts (charts)
- GitHub Pages (hosting)

## Pages
- / -> Dashboard (today tasks, pomodoro timer, progress)
- /plan -> Study Plan
- /quiz -> Quiz
- /analytics -> Analytics
- /settings -> Settings

## Rules
- Components: src/components/feature-name/
- Supabase client: src/lib/supabase.ts
- Types: src/types/
- UI language: Japanese
